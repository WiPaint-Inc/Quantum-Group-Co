# Cliffside residence

Drop the CAD export in this folder. The site serves it from `/estates/cliffside/web/`.

Metres, Y-up. Origin at the estate centre, on the ground. Sea is +Z. FOV 46.

- `cliffside_web.glb`
- `cliffside_web_lod1.glb`
- `cliffside_web_lod2.glb`
- `cliffside_web_wireframe.glb`
- `cliffside_vegetation.json`
- `cliffside_camera_path.json`
- `cliffside_mep.glb` (optional MEP layer)

Until these files are here, the engineering fly-in uses the placeholder glass shell and the animated services.
