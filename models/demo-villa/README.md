# Demo Villa models (parked)

These glTF files are not served. The walkthrough reads `public/models/demo-villa/` only, and only when `DRAFT_CONTENT=true`.

- `demo-villa.glb`
- `demo-villa-wireframe.glb`
- `demo-villa-structure.glb`

Copy a file into `public/models/demo-villa/` when it should load. `demo-villa-wireframe.glb` is the blueprint alias. Naming, the optional finished and interior files, and the fallback video are in [`docs/DEMO-VILLA.md`](../../docs/DEMO-VILLA.md).

The name on every file is Demo Villa. Do not attach a client, a place, or a price to them.
